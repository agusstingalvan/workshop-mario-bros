# Verification

1. Discover existing build, test, lint, engine, and manual-playtest commands.
2. Match verification to the requested change. Do not invent a passing result.
3. Record commands, outcomes, logs, captures, or manual steps as evidence.
4. If verification is unavailable, report the gap and the next human check required.
