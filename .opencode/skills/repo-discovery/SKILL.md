# Repository Discovery

1. Identify the project type, package or engine configuration, source layout, tests, and build commands.
2. Read the closest project instructions before editing.
3. Report facts with file paths. Separate observations from assumptions.
4. Propose the smallest relevant scope and ask questions if acceptance criteria are missing.
